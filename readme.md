这是一个浏览器插件的落地页面仓库


项目背景介绍：Riven OCR Assistant
1. 基本信息
名称：Riven OCR Assistant (裂罅 Mod 识别助手)
定位：一款专为游戏《Warframe》(星际战甲) 玩家设计的浏览器扩展插件。
核心痛点：玩家在 warframe.market 网站拍卖“裂罅 Mod”（俗称紫卡）时，需要手动输入复杂的武器名称、属性数值、段位、极性等信息，极其耗时且易出错。
2. 核心功能
智能图像识别 (OCR)：用户只需上传或粘贴紫卡截图，插件通过远程服务器自动识别所有关键数据（武器名、词条名、数值、等级、极性、洗炼次数等）。
一键自动填表：识别成功后，点击“写入页面”按钮，插件会自动打开 warframe.market 的拍卖模态框，并智能模拟用户操作，将所有数据瞬间填入表单。
市场行情查询：内置 Riven Tracker 接口，识别后即时显示该武器在市场上的昨日底价均价，帮助用户科学定价。
个性化设置：支持自定义后端 OCR URL、自动补全行数、自动打开模态框、深色/浅色主题切换等。
3. 技术架构
前端规范：采用 Chrome Extension Manifest V3 标准开发。
开发语言：TypeScript + Vite。
交互逻辑：使用 Content Scripts 与页面 DOM 交互，Background Service Worker 处理跨域 OCR 请求。
后端服务：独立的远程 OCR 解析服务器（基于 IP：49.234.200.196:80）。
4. 隐私与安全（用于编写隐私页面）
图像数据：插件捕获的图像仅发送至用户指定的后端服务器用于 OCR 文本提取，不会在服务器上进行永久存储。
权限使用：
storage：仅用于保存用户的个性化设置（如 URL、主题、历史记录）。
host_permissions：仅限于 warframe.market、OCR 后端服务器和价格查询 API。
不搜集信息：插件不收集、不追踪、不共享任何用户的个人敏感信息、浏览器历史记录或账号密码。
5. 目标用户
《Warframe》的活跃交易玩家，尤其是那些拥有大量紫卡需要快速上架的专业卖家。
